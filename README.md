# Data Cleaning & Summary Analysis

## Overview
Transform an uncleaned dataset into a structured, organised, and insight-ready summary sheet using Microsoft Excel.

## Objectives
- Clean and structure the raw dataset.
- Extract day, month, and country code from Product ID.
- Prepare the data for filtering, grouping, and analysis.
- Summarise key product and price metrics.
- Classify products by price range to understand distribution patterns.

## Tools Used
- Microsoft Excel
- Excel Tables
- Data extraction formulas
- Summary calculations

## Actions Performed

### Data Preparation
- Converted the raw dataset into an Excel table.
- Applied consistent formatting.
- Enabled dynamic range expansion for easier data handling.

### Product ID Extraction
- Separated day, month, and country code embedded in Product ID.
- Used the extracted fields to support filtering, grouping, and further analysis.

### Summary Sheet Development
- Calculated total price.
- Summarised product count.
- Calculated average price.
- Calculated category-wise totals.
- Classified products based on price range.

## Observations
- The Excel table provided a consistent structure for handling the dataset.
- Extracted Product ID details made the data suitable for filtering and grouping.
- Summary metrics provided an organised view of product counts and pricing.
- Price-range classification supported analysis of product distribution.
- The process converted an unstructured dataset into an insight-ready summary sheet.
